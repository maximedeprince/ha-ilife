# ILIFE Vacuum

Cloud integration for **ILIFE** robot vacuums (ILIFEHOME app) with a premium
all‑in‑one Lovelace card: live map, controls, suction/water/mode, carpet,
schedules and a clickable cleaning history with each day's map.

Configure with your ILIFEHOME **email / password / region** — the card and all
entities are set up automatically. Multiple vacuums and accounts are supported.

Tested on **ILIFE V3x**, EU region.
